Small Kits. Big First Moves.

Your first chess night starts here.

Noble Raven makes portable chess kits for curious beginners: a board, a full set of pieces, illustrated movement cards, and a notebook for the moves worth remembering. Bring one to a campus lounge, an apartment game night, or a quiet table with a friend.

We keep the collection small so choosing a first set feels easy. Each kit builds on the same friendly idea: learn a move, try a game, and come back with a question. This is a fictional shop created for a web design class.
