About

This course site demonstrates my work for ITIS3135 - Front-End Web Application Development at the University of North Carolina at Charlotte, taught by Mr. D.I. von Briesen. The instructor's teaching site provides more information about the course and its standards.

The course gives students practical experience with front-end web application development by building several websites with different purposes. I'll use HTML, CSS, and JavaScript to practice designing pages, connecting them, testing them, and publishing my work. My personal homepage introduces me, this course site collects my assignments, and Reddi Designs represents my fictional design firm.

Tools We Use

  • VS Code: Edit and organize website files.
  • Emmet within VS Code: Expand shortcuts into HTML and CSS.
  • SFTP via FileZilla: Transfer local files to Charlotte's webspace.
  • Git via GitHub Desktop and GitHub.com: Track changes and publish the GitHub Pages copy of the site.
  • Browser tools: Inspect layouts, debug code, and test navigation.
  • The Accumulus Validator: Check HTML and review accessibility feedback.
  • The Vicunadator: Check pages against the course standards.
